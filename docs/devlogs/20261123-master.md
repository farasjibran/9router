# Merge upstream dan keamanan statistik penggunaan

**Branch:** `master`

**Tanggal:** 2026-11-23

## Ringkasan

Menyelesaikan konflik merge upstream dengan mempertahankan konfigurasi kedua sisi dan metadata model NVIDIA yang relevan. Mencegah kunci API mentah muncul sebagai nama properti statistik penggunaan.

| File | Keterangan |

| `CHANGELOG.md`, `package.json` | Menggabungkan changelog dan versi upstream. |

| `tests/unit/usage-api-key-attribution.test.js` | Memeriksa pemisahan dan penyamaran kunci pada kedua periode. |

Kunci API tidak lagi digunakan sebagai nama properti pada respons statistik penggunaan; penyimpanan internal dan akses ke kunci tidak diubah. Snapshot dan tes lama diperbarui sesuai kontrak transport dan perilaku yang berlaku.
